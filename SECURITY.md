# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in Art Halloween Bats (`halloweenbats`) privately to [helpdesk@tecnoacquisti.com](mailto:helpdesk@tecnoacquisti.com), the security contact for Tecnoacquisti.com®.

Include module, PrestaShop, and PHP versions, reproduction steps, and potential impact. Share only information needed for investigation. Do not post unpatched vulnerabilities, credentials, or customer data in public issues.

If access credentials are necessary, follow our [secure credential submission instructions](https://www.tecnoacquisti.com/it/content/19-come-inviare-le-tue-password).

## Release and support information

The source reviewed is version 1.0.3. Existing documentation lists PrestaShop 1.7.0 through 9.0; PHP must be compatible with the installed PrestaShop release. The module metadata differs from that documentation; see [README.md](README.md).

A maintained release line and security support end date have not yet been approved for this module. This policy establishes a reporting contact, not a support commitment for every historical version. Contact us for the terms applicable to your distribution before relying on a support period.

## Security updates

Contact the address above or use our [help center](https://help.tecnoacquisti.com/) to request available security notices and update instructions for your module version. Obtain packages through the original delivery channel. The [module repository](https://github.com/ArteInfoRM/halloweenbats) provides source and release history. No dedicated public advisory feed was verified during this review.

Applicable security update availability is managed separately from commercial assistance and download subscriptions. Check the affected versions, compatibility requirements, backup instructions, and any required merchant action before applying an update.
